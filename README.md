# 3D-Path-Modeling
Tool for modeling 3D path for semi rigid cable assemblies

3dpath.py is python code for generating a curved 3D path from XYZ coordinates and bend radii. Currently programmed in Google Collab and includes feature for viewing 3D model in Google Collab. Future plans include integrating python code into an excel sheet for better accessibility

3DPath folder contains AutoCAD 3D LSP files for generating curved 3D path in autocad
